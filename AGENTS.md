## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.


This application is a personal web site for a freelance frontend consultant. When your are developing on this site make sure to break down the design handed to you into small - and if possible - reuseable components. There is an eslint.config.mjs file set for this project, whose rules should be followed and validated, to ensure we don't end up with giant components and files.

Paper.design MCP integration is available for developing the site. If you think the HTML or CSS from Paper can be improved, or simplified, without chaging the visuals, please do so.
